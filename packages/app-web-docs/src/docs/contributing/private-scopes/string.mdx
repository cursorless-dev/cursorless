# Parse tree string (String)

Cursorless ID: `string`

## Spoken form

Default: `parse tree string`

## Syntax

- parse tree string - String.

## Examples

- `"take parse tree string blue air"` - Selects the string containing the token containing letter `a` with a blue hat.

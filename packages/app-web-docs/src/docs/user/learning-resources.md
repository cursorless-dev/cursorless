# Learning resources

These resources can help you learn Cursorless, from your first commands through more advanced workflows.

## Start here

- [Cursorless tutorial videos](https://www.youtube.com/watch?v=5mAzHGM2M0k&list=PLXv2sppxeoQZz49evjy4T0QJRIgc_JPqs) - Learn the basic concepts and commands.
- [Interactive tutorial](./scope-sidebar.md#tutorial) - Learn Cursorless inside your editor using the Cursorless sidebar.

## Learn from examples

- [Cursorless by example](https://www.youtube.com/watch?v=2hPwfBCtXws&list=PLbN8ceamGu2c6JrNf83EWyP6K5K77MzVZ) - Watch Cursorless applied to practical editing tasks.
- [Cursorless: A spoken language for editing code](https://youtu.be/NcUJnmBqHTY) - Learn the ideas behind Cursorless in this Strange Loop talk.
- [Pokey's Cursorless videos](https://www.youtube.com/@PokeyRuleJams) - See demonstrations of Cursorless features and workflows.
- [Andreas's Cursorless videos](https://www.youtube.com/@andreas_arvidsson) - See demonstrations of Cursorless and Talon features.

## Practice and reference

- [Cursorless cheatsheet](https://www.cursorless.org/cheatsheet) - Look up actions, scopes, modifiers, and other spoken forms.
- [Scope visualizer](./scope-visualizer.md) - Explore which Cursorless scopes are available in your code.
- [Cursorless katas](https://github.com/Will-Sommers/cursorless-katas) - Exercises and challenges.

## Talon and community resources

- [Talon documentation](https://talonvoice.com/docs) - Learn about Talon concepts and APIs from the official documentation.
- [Talon Community Wiki](https://talon.wiki) - Find community-maintained guides, integrations, and customization resources.
- [Talon Slack](https://talonvoice.com/chat) - Ask questions and connect with the Talon community.
- [Talon Search](https://search.talonvoice.com) - Search Talon Community and other users' GitHub repositories for Talon scripts.
- [Cursorless GitHub Discussions](https://github.com/cursorless-dev/cursorless/discussions) - Ask questions and discuss Cursorless ideas and workflows.

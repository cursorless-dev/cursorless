# Recommendations

These optional recommendations can improve your Cursorless workflow but are not required by Cursorless.

## VS Code

- To show search results in an editor instead of the sidebar, set `"search.mode"` to `"reuseEditor"`.
- To inspect VS Code's default keyboard shortcuts and their command identifiers, run **Preferences: Open Default Keyboard Shortcuts (JSON)** (`"please default keyboard"`).

# Clone up (Insert copy before)

After insertion, each selection moves to its newly created copy.

Cursorless ID: `insertCopyBefore`

## Spoken form

Default: `clone up`

## Syntax

- clone up `<target>` - Insert copy before `<target>`.

## Examples

- `"clone up funk blue air"` - Inserts a copy of the function containing the token containing letter `a` with a blue hat before itself.

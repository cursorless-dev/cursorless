# Copy (Copy to clipboard)

Cursorless ID: `copyToClipboard`

## Spoken form

Default: `copy`

## Syntax

- copy `<target>` - Copy `<target>` to clipboard.

## Examples

- `"copy blue air"` - Copies the token containing letter `a` with a blue hat to the clipboard.

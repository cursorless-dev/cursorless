# Snip make (Generate snippet)

Cursorless ID: `generateSnippet`

## Spoken form

Default: `snip make`\
Legacy: `snippet make`

## Syntax

- snip make `<target>`: Generate snippet from `<target>`.

## Examples

- `"snip make funk blue air"`: Generates a snippet from the function containing the token containing letter 'a' with a blue hat.

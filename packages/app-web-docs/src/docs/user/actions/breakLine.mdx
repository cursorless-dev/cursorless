# Break (Break line)

Cursorless ID: `breakLine`

## Spoken form

Default: `break`

## Syntax

- break `<target>` - Breaks the line before `<target>`.

## Examples

- `"break blue air"` - Breaks the line before the token containing letter `a` with a blue hat.

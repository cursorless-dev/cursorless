# From (Set instance reference)

Sets the instance reference for the next 'instance of' action.

Cursorless ID: `experimental.setInstanceReference`

## Spoken form

Default: `from`

## Syntax

- from `<target>` - Set instance reference to `<target>`.

## Examples

- `"from funk blue air take every instance green bat"` - Selects every instance of the token containing letter 'b' with a green hat within the function containing the token containing letter 'a' with a blue hat.

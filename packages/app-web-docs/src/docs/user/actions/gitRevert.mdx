# Git revert

Cursorless ID: `gitRevert`

## Spoken form

Default: `git revert`

## Syntax

- git revert `<target>` - Revert Git change at `<target>`.

## Examples

- `"git revert blue air"` - Reverts the Git change on the line containing the token containing letter 'a' with a blue hat.

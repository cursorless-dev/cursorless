# Take (Select)

When used with a list target, this action creates one cursor for each target.

Cursorless ID: `setSelection`

## Spoken form

Default: `take`

## Syntax

- take `<target>` - Select `<target>`.

## Examples

- `"take blue air"` - Selects the token containing letter `a` with a blue hat.

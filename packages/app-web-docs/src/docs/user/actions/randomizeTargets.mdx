# Shuffle (Randomize targets)

Cursorless ID: `randomizeTargets`

## Spoken form

Default: `shuffle`

## Syntax

- shuffle `<target>`: Randomize `<target>`s.

## Examples

- `"shuffle every item blue air"`: Randomizes the collection items associated with the token containing letter 'a' with a blue hat.

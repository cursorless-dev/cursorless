# Format (Apply formatter)

Cursorless ID: `applyFormatter`

## Spoken form

Default: `format`

## Syntax

- format `<formatter>` at `<target>` - Reformat `<target>` as `<formatter>`.

## Examples

- `"format camel at blue air"` - Reformats the token containing letter `a` with a blue hat as camel case.

# Give (Deselect)

Cursorless ID: `deselect`

## Spoken form

Default: `give`

## Syntax

- give `<target>` - Deselect `<target>`.

## Examples

- `"give blue air"` - Removes the token containing letter `a` with a blue hat from the current selections.

# Snip (Insert snippet)

Cursorless ID: `insertSnippet`

## Spoken form

Default: `snip`

## Syntax

- snip `<snippet>` `<destination>` - Insert snippet at `<destination>`.

## Examples

- `"snip if after blue air"` - Inserts an if-statement snippet after the token containing letter `a` with a blue hat.

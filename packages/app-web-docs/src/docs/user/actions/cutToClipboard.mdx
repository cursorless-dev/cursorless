# Carve (Cut to clipboard)

Cursorless ID: `cutToClipboard`

## Spoken form

Default: `carve`

## Syntax

- carve `<target>` - Cut `<target>` to clipboard.

## Examples

- `"carve blue air"` - Cuts the token containing letter `a` with a blue hat to the clipboard.

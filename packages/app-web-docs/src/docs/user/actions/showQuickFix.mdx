# Quick fix (Show quick fix)

Shows the editor's quick fix menu.

Cursorless ID: `showQuickFix`

## Spoken form

Default: `quick fix`

## Syntax

- quick fix `<target>` - Show quick fix for `<target>`.

## Examples

- `"quick fix blue air"` - Shows quick fixes for the token containing letter `a` with a blue hat.

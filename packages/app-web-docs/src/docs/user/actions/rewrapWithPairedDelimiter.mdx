# Repack (Rewrap with paired delimiter)

See [paired delimiters](../paired-delimiters.md) for the available pairs.

Cursorless ID: `rewrap`

## Spoken form

Default: `repack`

## Syntax

- `<pair>` repack `<target>` - Rewrap `<target>` with `<pair>`.

## Examples

- `"curly repack blue air"` - Replaces the paired delimiters around the token containing letter `a` with a blue hat with curly brackets.

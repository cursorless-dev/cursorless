# Post (Set selection after)

When used with a list target, this action creates one cursor for each target.

Cursorless ID: `setSelectionAfter`

## Spoken form

Default: `post`

## Syntax

- post `<target>` - Set empty selection after `<target>`.

## Examples

- `"post blue air"` - Places the cursor after the token containing letter `a` with a blue hat.

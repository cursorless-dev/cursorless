# Append (Add selection)

Cursorless ID: `addSelection`

## Spoken form

Default: `append`

## Syntax

- append `<target>` - Adds `<target>` to the current selection set.

## Examples

- `"append blue air"` - Adds the token containing letter `a` with a blue hat to the current selections.

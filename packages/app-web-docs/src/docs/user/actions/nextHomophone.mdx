# Phones (Next homophone)

Cycles through words that sound alike, such as changing `where` to `wear`.

Cursorless ID: `nextHomophone`

## Spoken form

Default: `phones`

## Syntax

- phones `<target>` - Cycle to next homophone for `<target>`.

## Examples

- `"phones blue air"` - Replaces the token containing letter `a` with a blue hat with its next homophone.

# Comment (Toggle line comment)

Cursorless ID: `toggleLineComment`

## Spoken form

Default: `comment`

## Syntax

- comment `<target>` - Toggle line comment at `<target>`.

## Examples

- `"comment blue air"` - Toggles the comment on the line containing the token containing letter `a` with a blue hat.

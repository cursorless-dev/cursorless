# Crown (Scroll to top)

Scrolls the target to the top of the viewport. In a notebook scrolls the cell containing the target to the top of the viewport.

Cursorless ID: `scrollToTop`

## Spoken form

Default: `crown`

## Syntax

- crown `<target>` - Scroll `<target>` to top of the viewport.

## Examples

- `"crown blue air"` - Scrolls the token containing letter `a` with a blue hat to the top of the viewport.

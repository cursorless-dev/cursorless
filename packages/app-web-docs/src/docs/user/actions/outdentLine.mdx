# Dedent (Outdent line)

Cursorless ID: `outdentLine`

## Spoken form

Default: `dedent`

## Syntax

- dedent `<target>` - Outdent line containing `<target>`.

## Examples

- `"dedent blue air"` - Decreases the indentation of the line containing the token containing letter `a` with a blue hat.

# Join (Join lines)

When the target spans multiple lines, joins all of those lines; otherwise joins the target's line with the following line.

Cursorless ID: `joinLines`

## Spoken form

Default: `join`

## Syntax

- join `<target>` - Join lines at `<target>`.

## Examples

- `"join blue air"` - Joins the line containing the token containing letter `a` with a blue hat with the following line.

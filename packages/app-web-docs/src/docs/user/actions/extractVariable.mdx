# Extract (Extract variable)

Uses the editor's extract-variable refactoring.

Cursorless ID: `extractVariable`

## Spoken form

Default: `extract`

## Syntax

- extract `<target>` - Extract variable from `<target>`.

## Examples

- `"extract value blue air"` - Extracts the value containing the token containing letter 'a' with a blue hat into a variable.

# Append pre (Add selection before)

Cursorless ID: `addSelectionBefore`

## Spoken form

Default: `append pre`

## Syntax

- append pre `<target>` - Adds empty selection before `<target>` to the current selection set.

## Examples

- `"append pre blue air"` - Adds an empty selection before the token containing letter `a` with a blue hat.

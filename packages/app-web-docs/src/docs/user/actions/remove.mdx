# Chuck (Remove)

This action can be used to remove a target without moving the cursor.

Cursorless ID: `remove`

## Spoken form

Default: `chuck`

## Syntax

- chuck `<target>` - Remove `<target>`.

## Examples

- `"chuck blue air"` - Removes the token containing letter `a` with a blue hat.

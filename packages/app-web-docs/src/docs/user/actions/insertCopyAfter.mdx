# Clone (Insert copy after)

After insertion, each selection moves to its newly created copy.

Cursorless ID: `insertCopyAfter`

## Spoken form

Default: `clone`

## Syntax

- clone `<target>` - Insert copy after `<target>`.

## Examples

- `"clone funk blue air"` - Inserts a copy of the function containing the token containing letter `a` with a blue hat after itself.

# Center (Scroll to center)

Cursorless ID: `scrollToCenter`

## Spoken form

Default: `center`

## Syntax

- center `<target>` - Scroll `<target>` to center of the viewport.

## Examples

- `"center blue air"` - Scrolls the token containing letter `a` with a blue hat to the center of the viewport.

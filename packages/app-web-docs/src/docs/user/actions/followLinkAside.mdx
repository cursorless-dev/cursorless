# Follow split (Follow link aside)

Cursorless ID: `followLinkAside`

## Spoken form

Default: `follow split`

## Syntax

- follow split `<target>` - Follow link at `<target>` aside (e.g. in a split view).

## Examples

- `"follow split blue air"` - Opens the link containing the token containing letter 'a' with a blue hat in a split view.

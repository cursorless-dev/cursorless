# Git unstage

Cursorless ID: `gitUnstage`

## Spoken form

Default: `git unstage`

## Syntax

- git unstage `<target>` - Unstage Git change at `<target>`.

## Examples

- `"git unstage blue air"` - Unstages the Git change on the line containing the token containing letter 'a' with a blue hat.

# Float (Insert empty line/scope after)

Scope defaults to line. When used with a provided scope target, this action inserts the delimiters or spacing required for a new instance of that scope.

Cursorless ID: `insertEmptyLineAfter`

## Spoken form

Default: `float`

## Syntax

- float `<target>` - Insert empty line/scope after `<target>`.

## Examples

- `"float blue air"` - Inserts an empty line below the token containing letter `a` with a blue hat without moving the cursor.
- `"float item blue air"` - Inserts the required delimiter after the collection item containing the token containing letter `a` with a blue hat.

# Append post (Add selection after)

Cursorless ID: `addSelectionAfter`

## Spoken form

Default: `append post`

## Syntax

- append post `<target>` - Adds empty selection after `<target>` to the current selection set.

## Examples

- `"append post blue air"` - Adds an empty selection after the token containing letter `a` with a blue hat.

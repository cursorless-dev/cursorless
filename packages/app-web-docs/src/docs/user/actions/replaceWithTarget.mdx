# Replace with target

Cursorless ID: `replaceWithTarget`

## Spoken form

Default: `bring`

## Syntax

- bring `<target>`: Insert copy of `<target>` at selection.
- bring `<target>` `<destination>`: Copy `<target>` to `<destination>`.

## Examples

- `"bring blue air to green bat"`: Replaces the token containing letter 'b' with a green hat with a copy of the token containing letter 'a' with a blue hat.

# Move (Move to target)

A target destination is replaced, while a position destination such as `before` or `after` inserts there. The source is removed from its original location in either case.

Cursorless ID: `moveToTarget`

## Spoken form

Default: `move`

## Syntax

- move `<target>` - Move `<target>` to selection.
- move `<target>` `<destination>` - Move `<target>` to `<destination>`.

## Examples

- `"move blue air"` - Moves the token containing letter `a` with a blue hat to the current selection.
- `"move blue air after green bat"` - Moves the token containing letter `a` with a blue hat to after the token containing letter `b` with a green hat.

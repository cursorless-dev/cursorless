# Swap (Swap targets)

When both operands contain multiple targets, their targets are paired by position and swapped.

Cursorless ID: `swapTargets`

## Spoken form

Default: `swap`

## Syntax

- swap with `<target>` - Swap selection with `<target>`.
- swap `<target 1>` with `<target 2>` - Swap `<target 1>` with `<target 2>`.

## Examples

- `"swap with blue air"` - Swaps the current selection with the token containing letter `a` with a blue hat.
- `"swap blue air with green bat"` - Swaps the token containing letter `a` with a blue hat and the token containing letter `b` with a green hat.

# Break point (Toggle line/scope breakpoint)

Scope defaults to line.

Cursorless ID: `toggleLineBreakpoint`

## Spoken form

Default: `break point`

## Syntax

- break point `<target>` - Toggle breakpoint on line containing `<target>`.
- break point token `<target>` - Toggle inline breakpoint at `<target>`.

## Examples

- `"break point blue air"` - Toggles a breakpoint on the line containing the token containing letter 'a' with a blue hat.
- `"break point token blue air"` - Toggles an inline breakpoint at the token containing letter 'a' with a blue hat.

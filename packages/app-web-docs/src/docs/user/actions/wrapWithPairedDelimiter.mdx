# Wrap (Wrap with paired delimiter/snippet)

See [paired delimiters](../README.md#paired-delimiters) for the available pairs.

Cursorless ID: `wrapWithPairedDelimiter`

## Spoken form

Default: `wrap`

## Syntax

- `<pair>` wrap `<target>` - Wrap `<target>` with `<pair>`.
- `<snippet>` wrap `<target>` - Wrap `<target>` with `<snippet>`.

## Examples

- `"box wrap blue air"` - Wraps the token containing letter 'a' with a blue hat in square brackets.
- `"if wrap blue air"` - Wraps the token containing letter 'a' with a blue hat in an if-statement snippet.

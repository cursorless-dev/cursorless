# Sort (Sort targets)

This action changes the order of multiple target contents. The targets can come from a list or range target, or from existing multiple selections.

Cursorless ID: `sortTargets`

## Spoken form

Default: `sort`

## Syntax

- sort `<target>` - Sort `<target>`s.

## Examples

- `"sort every item blue air"` - Sorts the collection items associated with the token containing letter `a` with a blue hat.
- `"sort line blue air slice green bat"` - Sorts the lines from the token containing letter `a` with a blue hat through the token containing letter `b` with a green hat.
- `"sort this"` - Sorts the current selections.

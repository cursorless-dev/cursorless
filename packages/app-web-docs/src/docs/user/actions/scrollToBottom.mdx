# Bottom (Scroll to bottom)

Scrolls the target to the bottom of the viewport. In a notebook this is not supported due to a limitation in VS Code's notebook API.

Cursorless ID: `scrollToBottom`

## Spoken form

Default: `bottom`

## Syntax

- bottom `<target>` - Scroll `<target>` to bottom of the viewport.

## Examples

- `"bottom blue air"` - Scrolls the token containing letter `a` with a blue hat to the bottom of the viewport.

# Reverse (Reverse targets)

Cursorless ID: `reverseTargets`

## Spoken form

Default: `reverse`

## Syntax

- reverse `<target>`: Reverse `<target>`s.

## Examples

- `"reverse every item blue air"`: Reverses the collection items associated with the token containing letter 'a' with a blue hat.

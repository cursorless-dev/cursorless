# Change

Cursorless ID: `clearAndSetSelection`

## Spoken form

Default: `change`\
Legacy: `clear`

## Syntax

- change `<target>`: Change `<target>` by clearing it and leaving the cursor in its place.

## Examples

- `"change blue air"`: Changes the token containing letter 'a' with a blue hat by clearing it and leaving the cursor in its place.

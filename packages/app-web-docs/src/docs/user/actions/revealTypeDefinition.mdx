# Type deaf (Reveal type definition)

Cursorless ID: `revealTypeDefinition`

## Spoken form

Default: `type deaf`

## Syntax

- type deaf `<target>` - Reveal type definition of `<target>`.

## Examples

- `"type deaf blue air"` - Opens the type definition of the token containing letter 'a' with a blue hat.

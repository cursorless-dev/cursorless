# Decrement

Cursorless ID: `decrement`

## Spoken form

Default: `decrement`

## Syntax

- decrement `<target>` - Decrement number at `<target>`.

## Examples

- `"decrement blue five"` - Decrements the number at the token containing number `5` with a blue hat.

# Indent (Indent line)

Cursorless ID: `indentLine`

## Spoken form

Default: `indent`

## Syntax

- indent `<target>` - Indent line containing `<target>`.

## Examples

- `"indent blue air"` - Indents the line containing the token containing letter `a` with a blue hat.

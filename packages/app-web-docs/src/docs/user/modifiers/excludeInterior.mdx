# Bounds (Exclude interior)

Cursorless ID: `excludeInterior`

## Spoken form

Default: `bounds`

## Syntax

- bounds - Bounding paired delimiters.

## Examples

- `"take bounds round blue air"` - Selects only the parentheses containing the token containing letter `a` with a blue hat.
- `"chuck bounds blue air"` - Removes the boundaries containing the token containing letter `a` with a blue hat.

# Tail (Extend through end of)

Cursorless ID: `extendThroughEndOf`

## Spoken form

Default: `tail`

## Syntax

- tail: Extend through end of line/pair.
- tail `<modifier>`: Extend through end of `<modifier>`.

## Examples

- `"take tail blue air"`: Selects from the token containing letter 'a' with a blue hat through the end of its line or surrounding pair.
- `"take tail state blue air"`: Selects from the token containing letter 'a' with a blue hat through the end of its containing statement.

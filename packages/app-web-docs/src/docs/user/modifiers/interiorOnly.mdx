# Inside (Interior only)

Cursorless ID: `interiorOnly`

## Spoken form

Default: `inside`

## Syntax

- inside - Interior only.

## Examples

- `"take inside round blue air"` - Selects the contents of the parentheses containing the token containing letter `a` with a blue hat, excluding the parentheses.

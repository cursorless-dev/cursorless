# Every (Every scope)

Selects all matching sibling scopes. It can also prefix an ordinal or relative modifier to return separate targets instead of one contiguous range.

Cursorless ID: `everyScope`

## Spoken form

Default: `every`

## Syntax

- every `<scope>` - Every instance of `<scope>`.

## Examples

- `"take every item blue air"` - Selects every item in the map containing the token containing letter 'a' with a blue hat.

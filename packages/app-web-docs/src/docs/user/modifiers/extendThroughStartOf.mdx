# Extend through start of

Cursorless ID: `extendThroughStartOf`

## Spoken form

Default: `head`

## Syntax

- head: Extend through start of line/pair.
- head `<modifier>`: Extend through start of `<modifier>`.

## Examples

- `"take head blue air"`: Selects from the token containing letter 'a' with a blue hat through the start of its line or surrounding pair.

# Head (Extend through start of)

Extends a target through the start of its line. Inside a surrounding pair, it stops at the start of the pair's interior; use an explicit scope such as `"head line"` to override that boundary.

Cursorless ID: `extendThroughStartOf`

## Spoken form

Default: `head`

## Syntax

- head - Extend through start of line/pair.
- head `<modifier>` - Extend through start of `<modifier>`.

## Examples

- `"take head blue air"` - Selects from the token containing letter 'a' with a blue hat through the start of its line or surrounding pair.
- `"take head state blue air"` - Selects from the token containing letter 'a' with a blue hat through the start of its containing statement.

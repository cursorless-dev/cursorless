# Containing scope

Expands a target to the containing instance of a scope. When the input is `"this"` with multiple selections, Cursorless expands each selection independently.

Cursorless ID: `containingScope`

## Syntax

- `<scope>` - Containing instance of `<scope>`.

## Examples

- `"take state blue air"` - Selects the statement containing the token containing letter `a` with a blue hat.

# Its (Infer previous mark)

Within a compound target, applies the following modifier to the previously mentioned mark. Without `"its"`, an implicit target such as `"line"` is resolved relative to the current selection instead.

Cursorless ID: `inferPreviousMark`

## Spoken form

Default: `its`

## Syntax

- its - Infer previous mark.

## Examples

- `"take blue air past end of its line"` - Selects from the token containing letter `a` with a blue hat through the end of the line containing that token.
- `"bring blue air to its value"` - Replaces the value containing the token containing letter `a` with a blue hat with that token.

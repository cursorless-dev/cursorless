# Key (Collection key)

Cursorless ID: `collectionKey`

## Spoken form

Default: `key`

## Syntax

- key - Key in a map, object, or dictionary.

## Examples

- `"take key blue air"` - Selects the collection key containing the token containing letter `a` with a blue hat.

# Callee (Function callee)

Cursorless ID: `functionCallee`

## Spoken form

Default: `callee`

## Syntax

- callee - Expression invoked by a function call.

## Examples

- `"take callee blue air"` - Selects the function callee containing the token containing letter `a` with a blue hat.

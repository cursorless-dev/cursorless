# Call (Function call)

Cursorless ID: `functionCall`

## Spoken form

Default: `call`

## Syntax

- call - Function, method, or constructor call.

## Examples

- `"take call blue air"` - Selects the function call containing the token containing letter `a` with a blue hat.

# Branch

Cursorless ID: `branch`

## Spoken form

Default: `branch`

## Syntax

- branch - Branch of a control-flow construct, such as if, try, switch, or ternary.

## Examples

- `"take branch blue air"` - Selects the branch containing the token containing letter `a` with a blue hat.

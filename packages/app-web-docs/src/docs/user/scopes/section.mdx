# Section

Cursorless ID: `section`

## Spoken form

Default: `section`

## Syntax

- section - Heading and its content through the next heading of the same or higher level.

## Examples

- `"take section blue air"` - Selects the section containing the token containing letter 'a' with a blue hat.

# Funk (Named function)

Cursorless ID: `namedFunction`

## Spoken form

Default: `funk`

## Syntax

- funk - Named function declaration.

## Examples

- `"take funk blue air"` - Selects the named function containing the token containing letter 'a' with a blue hat.

# Token

Expands the input to the nearest containing token. Without an explicit mark, it uses the token adjacent to the cursor or containing the current selection.

Cursorless ID: `token`

## Spoken form

Default: `token`

## Syntax

- token - Token such as a word, number, or operator.

## Examples

- `"take token blue air"` - Selects the token containing letter 'a' with a blue hat.

# Bounded paragraph

Cursorless ID: `boundedParagraph`

## Spoken form

Default: `short block`

## Syntax

- short block: Paragraph bounded by surrounding pair delimiters.

## Examples

- `"take short block blue air"`: Selects the bounded paragraph containing the token containing letter 'a' with a blue hat.

# Condition

Cursorless ID: `condition`

## Spoken form

Default: `condition`

## Syntax

- condition - Condition of a conditional, loop, or similar construct.

## Examples

- `"take condition blue air"` - Selects the condition containing the token containing letter `a` with a blue hat.

# Element (XML element)

Cursorless ID: `xmlElement`

## Spoken form

Default: `element`

## Syntax

- element - Complete XML, HTML, or JSX element, or a LaTeX environment.

## Examples

- `"take element blue air"` - Selects the XML element containing the token containing letter 'a' with a blue hat.

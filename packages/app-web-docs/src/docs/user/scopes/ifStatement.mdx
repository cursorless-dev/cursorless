# If state (If statement)

Cursorless ID: `ifStatement`

## Spoken form

Default: `if state`

## Syntax

- if state - Complete if statement.

## Examples

- `"take if state blue air"` - Selects the if statement containing the token containing letter 'a' with a blue hat.

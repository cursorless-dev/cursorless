# Glyph

Cursorless ID: `glyph`

## Spoken form

Default: `glyph`

## Syntax

- glyph `<character>` - Instance of single character `<character>`.

## Examples

- `"take next glyph air"` - Selects the next `a`.
- `"take every glyph dollar"` - Selects every `$`.

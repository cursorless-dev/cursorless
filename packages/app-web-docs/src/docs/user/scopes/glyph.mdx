# Glyph

Cursorless ID: `glyph`

## Spoken form

Default: `glyph`

## Syntax

- glyph `<character>`: Instance of single character `<character>`.

## Examples

- `"take glyph blue air"`: Selects the character indicated by the token containing letter 'a' with a blue hat.

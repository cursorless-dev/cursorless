# Paint (Non-whitespace sequence)

Expands forward and backward from the input through adjacent non-whitespace characters.

Cursorless ID: `nonWhitespaceSequence`

## Spoken form

Default: `paint`

## Syntax

- paint - Non-whitespace sequence.

## Examples

- `"take paint blue air"` - Selects the non-whitespace sequence containing the token containing letter 'a' with a blue hat.

# Subparagraph

Cursorless ID: `subParagraph`

## Spoken form

Default: `subparagraph`

## Syntax

- subparagraph - Document subparagraph and its contents.

## Examples

- `"take subparagraph blue air"` - Selects the subparagraph containing the token containing letter `a` with a blue hat.

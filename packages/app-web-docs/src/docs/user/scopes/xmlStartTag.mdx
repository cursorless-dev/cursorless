# Start tag (XML start tag)

Cursorless ID: `xmlStartTag`

## Spoken form

Default: `start tag`

## Syntax

- start tag - Opening XML, HTML, or JSX tag, or LaTeX `begin` command.

## Examples

- `"take start tag blue air"` - Selects the XML start tag containing the token containing letter `a` with a blue hat.

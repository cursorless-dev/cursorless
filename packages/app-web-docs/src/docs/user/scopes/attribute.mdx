# Attribute

Cursorless ID: `attribute`

## Spoken form

Default: `attribute`

## Syntax

- attribute - Attribute, such as one on an HTML element.

## Examples

- `"take attribute blue air"` - Selects the attribute containing the token containing letter `a` with a blue hat.

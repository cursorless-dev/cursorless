# Value

Cursorless ID: `value`

## Spoken form

Default: `value`

## Syntax

- value - Value in an assignment, collection entry, return statement, or similar construct.

## Examples

- `"take value blue air"` - Selects the value containing the token containing letter `a` with a blue hat.

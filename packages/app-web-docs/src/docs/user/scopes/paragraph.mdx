# Block (Paragraph)

Expands above and below the input through contiguous nonempty lines, stopping at empty lines.

Cursorless ID: `paragraph`

## Spoken form

Default: `block`

## Syntax

- block - Paragraph, contiguous non-empty lines around the target.

## Examples

- `"take block blue air"` - Selects the paragraph containing the token containing letter `a` with a blue hat.

# File (Document)

The entire document, from the first to the last character.

Cursorless ID: `document`

## Spoken form

Default: `file`

## Syntax

- file - Entire document.

## Examples

- `"take file blue air"` - Selects the document containing the token containing letter `a` with a blue hat.

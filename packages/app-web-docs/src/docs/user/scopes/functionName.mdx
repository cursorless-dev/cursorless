# Funk name (Function name)

Cursorless ID: `functionName`

## Spoken form

Default: `funk name`

## Syntax

- funk name - Function name.

## Examples

- `"take funk name blue air"` - Selects the function name containing the token containing letter 'a' with a blue hat.

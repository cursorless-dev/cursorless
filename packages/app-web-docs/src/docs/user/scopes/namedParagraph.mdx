# Named paragraph

Cursorless ID: `namedParagraph`

## Spoken form

Default: `paragraph`

## Syntax

- paragraph: Named paragraph.

## Examples

- `"take paragraph blue air"`: Selects the named paragraph containing the token containing letter 'a' with a blue hat.

# End tag (XML end tag)

Cursorless ID: `xmlEndTag`

## Spoken form

Default: `end tag`

## Syntax

- end tag - Closing XML, HTML, or JSX tag, or LaTeX `end` command.

## Examples

- `"take end tag blue air"` - Selects the XML end tag containing the token containing letter 'a' with a blue hat.

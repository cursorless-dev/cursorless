# Identifier

Like a token, but limited to text that can act as an identifier, such as `foo`, `fooBar`, or `foo_bar`; operators such as `.`, `=`, and `+=` are excluded. This scope is useful with ordinals such as `last identifier`.

Cursorless ID: `identifier`

## Spoken form

Default: `identifier`

## Syntax

- identifier - Identifier-style sequence, such as camelCase, snake_case, or kebab-case.

## Examples

- `"take identifier blue air"` - Selects the identifier containing the token containing letter 'a' with a blue hat.

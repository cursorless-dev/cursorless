# Surrounding pair

Cursorless ID: `surroundingPair`

## Syntax

- `<pair>` - Surrounding matching delimiter pair and its contents.

## Examples

- `"take round blue air"` - Selects the parentheses containing the token containing letter 'a' with a blue hat.

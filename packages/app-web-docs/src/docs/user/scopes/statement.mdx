# State (Statement)

Cursorless ID: `statement`

## Spoken form

Default: `state`

## Syntax

- state - Complete statement, such as a variable declaration or expression statement.

## Examples

- `"take state blue air"` - Selects the statement containing the token containing letter 'a' with a blue hat.

# XML both tags

Cursorless ID: `xmlBothTags`

## Spoken form

Default: `tags`

## Syntax

- tags: XML start and end tags.

## Examples

- `"take tags blue air"`: Selects both tags of the XML element containing the token containing letter 'a' with a blue hat.

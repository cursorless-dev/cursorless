# Arg list (Argument list)

Cursorless ID: `argumentList`

## Spoken form

Default: `arg list`

## Syntax

- arg list: Argument list.

## Examples

- `"take arg list blue air"`: Selects the argument list containing the token containing letter 'a' with a blue hat.

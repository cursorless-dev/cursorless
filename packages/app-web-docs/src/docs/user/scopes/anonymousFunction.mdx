# Lambda (Anonymous function)

Cursorless ID: `anonymousFunction`

## Spoken form

Default: `lambda`

## Syntax

- lambda - Anonymous or lambda function.

## Examples

- `"take lambda blue air"` - Selects the anonymous function containing the token containing letter `a` with a blue hat.

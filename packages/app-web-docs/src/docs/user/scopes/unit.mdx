# Unit

Cursorless ID: `unit`

## Spoken form

Default: `unit`

## Syntax

- unit - Unit suffix in a measurement, such as `px` in `100px`.

## Examples

- `"take unit blue air"` - Selects the unit containing the token containing letter 'a' with a blue hat.

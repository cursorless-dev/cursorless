# Regex (Regular expression)

Cursorless ID: `regularExpression`

## Spoken form

Default: `regex`

## Syntax

- regex - Regular-expression literal.

## Examples

- `"take regex blue air"` - Selects the regular expression containing the token containing letter 'a' with a blue hat.

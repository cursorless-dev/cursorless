# Item (Collection item)

Cursorless ID: `collectionItem`

## Spoken form

Default: `item`

## Syntax

- item - Entry in a list, map, object, or similar collection.

## Examples

- `"take item blue air"` - Selects the collection item containing the token containing letter 'a' with a blue hat.

# Short paint (Bounded non-whitespace sequence)

Like `"paint"`, but expansion also stops at a delimiter pair that surrounds the input target. Delimiter pairs that do not surround the original target do not stop expansion.

Cursorless ID: `boundedNonWhitespaceSequence`

## Spoken form

Default: `short paint`

## Syntax

- short paint - Non-whitespace sequence bounded by surrounding pair delimiters.

## Examples

- `"take short paint blue air"` - Selects the bounded non-whitespace sequence containing the token containing letter `a` with a blue hat.

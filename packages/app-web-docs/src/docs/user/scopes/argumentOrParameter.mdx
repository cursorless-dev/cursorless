# Arg (Argument or parameter)

Cursorless ID: `argumentOrParameter`

## Spoken form

Default: `arg`

## Syntax

- arg - Function parameter or function-call argument.

## Examples

- `"take arg blue air"` - Selects the argument or parameter containing the token containing letter 'a' with a blue hat.
